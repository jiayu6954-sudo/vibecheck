## 正文

### 一、三个真实的坑

上周用 Cursor 写了个 Node.js 后端，开发很爽，测试也过了。

部署到线上，5 分钟后...

#### 坑 1：API Key 泄露

```javascript
// Cursor 生成的代码
const openai = new OpenAI({
  apiKey: "sk-abc123def456..."  // 😱 直接写死了
});
```

**后果：**
- 推送到 GitHub，5 分钟收到 Secret Scanning 警告
- 赶紧 revoke key，改成环境变量
- 浪费 20 分钟

**为什么 AI 会这样写？**
因为示例代码都是这样的，AI 学习了这个"坏习惯"。

---

#### 坑 2：SQL 注入

```javascript
// Cursor 生成的代码
app.get('/user/:id', async (req, res) => {
  const userId = req.params.id;
  const result = await db.query(
    `SELECT * FROM users WHERE id=${userId}`  // 😱 直接拼接
  );
  res.json(result);
});
```

**测试时没问题**，因为传的都是正常 ID。

**但如果有人传** `1 OR 1=1--`，整个用户表就泄露了。

**为什么 AI 会这样写？**
直接拼接"看起来更简洁"，而且在演示代码中很常见。

---

#### 坑 3：未处理的异步错误

```javascript
// Cursor 生成的代码
app.post('/upload', async (req, res) => {
  const file = await processFile(req.file);  // 如果这里报错呢？
  res.json({ success: true, file });
});
```

**开发环境没事，线上偶尔报：**
```
UnhandledPromiseRejectionWarning: ...
```

因为 `processFile` 可能抛出异常，但没有 `try-catch`。

### 二、为什么不直接问 Claude？

试了几次，发现 3 个问题：

#### 1. 提示词不好写

第一次：
> "帮我检查这段代码"

Claude：
> "代码看起来不错，结构清晰..."

第二次：
> "帮我检查这段代码的安全问题，特别是 SQL 注入、XSS、敏感信息泄露"

这次检查出来了，但**每次都要写这么长**，太累。

---

#### 2. 输出不统一

有时候：
- 长篇大论（200 字解释一个小问题）
- 太简略（只说"有风险"，不说怎么改）
- 顺序混乱（先说小问题，后说致命问题）

我想要的格式：
```
评分：75/100
Critical：1 个
High：2 个

[问题] + [位置] + [怎么改]
```

---

#### 3. 贵

Claude API：¥0.26/次

每天检查 10 次 = ¥2.6
一个月 = ¥78

对个人开发者，有点心疼。

### 四、发现的典型问题

上线 3 天，50+ 次扫描，统计了问题分布：

| 问题类型 | 次数 | 占比 |
|---------|------|------|
| 未处理异步错误 | 15 | 30% |
| 硬编码敏感信息 | 12 | 24% |
| SQL 注入风险 | 8 | 16% |
| 过度工程 | 6 | 12% |
| 其他 | 9 | 18% |

**结论：** 未处理异步错误最常见。

### 五、技术实现（简单说）

```
前端（Next.js） → 后端 API → DeepSeek API
                    ↓
                保存历史（Supabase）
```

**核心：专业的提示词**

```javascript
const SYSTEM_PROMPT = `
你是代码安全专家，检测 AI 生成代码的问题。

重点：
1. 硬编码密钥
2. SQL 注入、XSS
3. 未处理异步错误
4. 过度工程

输出：严格 JSON 格式
{
  "score": 0-100,
  "issues": [...]
}
`;
```

这个提示词调试了很久，比随手问 Claude 效果好。

### 六、局限性（重要）

**不能做什么：**
- ❌ 不能替代人工审查（复杂逻辑要人看）
- ❌ 不能检测所有漏洞（只是辅助工具）
- ❌ 可能有误报（AI 不完美）
- ❌ 没有 IDE 插件（要手动复制）

**适合谁：**
- ✅ 用 Cursor/Copilot 写代码的人
- ✅ 想快速检查常见问题的人
- ✅ 个人开发者（免费）

**不适合谁：**
- ❌ 需要企业级审查的团队
- ❌ 要求 100% 准确的场景

### 八、数据与开源

#### 隐私保护
- 代码只用于一次性扫描，不存储
- DeepSeek API 不保存数据
- 服务器只记录扫描次数

#### 开源计划
**为什么现在不开源？**
- 想先做稳定（避免一堆 issue）
- 代码质量需要提高
- 需要完整文档

**什么时候开源？**
- 核心功能稳定（误报率 <10%）
- 有 100 个用户验证
- 预计 1-2 个月后
