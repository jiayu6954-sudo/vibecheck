## 正文

### 你可能遇到过这些问题

用 Cursor/Copilot 写代码时：

**看起来能用 ✅**
- 代码生成快
- 测试通过

**但可能隐藏了 ❌**

#### 3. 典型问题检测

**检测 1：硬编码密钥（Critical）**

![硬编码检测](硬编码截图.png)

发现：
```javascript
const apiKey = "sk-abc123...";  // ❌ 危险
```

建议：
```javascript
const apiKey = process.env.API_KEY;  // ✅ 安全
```

---

**检测 2：SQL 注入风险（High）**

![SQL注入检测](SQL注入截图.png)

发现：
```javascript
const query = `SELECT * FROM users WHERE id=${userId}`;  // ❌ 不安全
```

建议：
```javascript
const query = 'SELECT * FROM users WHERE id=?';
db.query(query, [userId]);  // ✅ 使用参数化查询
```

---

**检测 3：未处理的异步错误（Medium）**

![异步错误检测](异步错误截图.png)

发现：
```javascript
await fetch(url);  // ❌ 没有错误处理
```

建议：
```javascript
try {
  await fetch(url);
} catch (error) {
  console.error(error);
}  // ✅ 添加错误处理
```

### 适合谁用

**✅ 适合：**
- 用 Cursor/Copilot/Claude Code 写代码
- 想快速检查常见问题
- 个人开发者 / 小团队

**❌ 不适合：**
- 需要 100% 准确的企业级审查
- 复杂业务逻辑的深度分析
- 已有完善代码审查流程的大团队

---

### 局限性（重要）

**这个工具：**
- 只能检测常见问题（不是全能的）
- 可能有误报（底层是 AI）
- 不能替代人工代码审查
- 目前没有 IDE 插件（要手动复制粘贴）

**建议：**
- Critical/High 问题：一定要检查
- Medium/Low 问题：作为参考
